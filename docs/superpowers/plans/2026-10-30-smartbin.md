# SmartBin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a VGG16 transfer-learning waste classifier on TrashNet. Run 4–5 one-change-at-a-time experiments, compare them, and serve the best model in a Gradio app.

**Architecture:** Small tested Python modules (`model.py`, `data.py`, `train.py`, `report.py`, `app.py`) hold all the logic. A Colab notebook only imports them and runs the experiments on a GPU. The app rebuilds the model from the checkpoint's `exp_id`, so training and serving always share one definition.

**Tech Stack:** Python 3.10+, PyTorch + torchvision, scikit-learn (metrics, split), pandas, matplotlib, Gradio 4.x, pytest. Training runs on Google Colab (T4). Tests and the app run locally on CPU (Windows).

**Spec:** `docs/superpowers/specs/2026-10-30-smartbin-design.md`

**Deviation from spec (intentional):** the spec has the notebook write `model.py` with `%%writefile`. Instead, the project folder is copied to Google Drive and the notebook imports the modules from there. This keeps a single copy of the code, which is what the spec wanted. The spec's notebook cells are split into `data.py`, `train.py` and `report.py` so they can be tested.

## Global Constraints

- Class order (fixed everywhere): `["cardboard", "glass", "metal", "paper", "plastic", "trash"]`
- Split: stratified 70 / 15 / 15 train / val / test, seed `42`, saved to `splits.csv`
- Train transform: `RandomResizedCrop(224, scale=(0.8, 1.0))`, `RandomHorizontalFlip()`, `ToTensor()`, `Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])`
- Eval transform: `Resize(256)`, `CenterCrop(224)`, `ToTensor()`, same `Normalize`
- Training: batch size 32, 10 epochs, `CrossEntropyLoss`. Keep the best-val-accuracy checkpoint. Evaluate on test once per experiment.
- Experiment IDs: `"E1"`, `"E2"`, `"E3"`, `"E4"`, `"E5"`. Hyperparameters exactly as in spec §4.
- Checkpoint format: `{"exp_id": str, "classes": list[str], "state_dict": dict, "test_acc": float}`
- App low-confidence threshold: top probability `< 0.5`, which shows the message `"Not sure. Try a clearer photo of one item on a plain background"`
- Target: best model ≥ 0.85 test accuracy
- Tests never download pretrained weights (`pretrained=False`) and run on CPU

## Review Focus

1. **Phone photos with EXIF rotation**: a portrait phone photo must be classified upright. `predict` applies `ImageOps.exif_transpose`. Test in Task 5.
2. **Tiny or huge images** (e.g. 40×40, 4000×3000): `predict` must not crash, because the eval transform resizes them. Test in Task 5.
3. **Checkpoint/architecture mismatch**: the E5 (MobileNetV2) or E1 checkpoint must load into the right architecture. Save/load round-trip test for every `exp_id` in Task 5.
4. **Colab disconnects mid-run**: rerunning the notebook must skip experiments already in `results.csv` and not overwrite them. Test `pending_experiments` in Task 3.
5. **Folder order or extra folders in the dataset zip**: labels must come from `CLASSES`, not from the order the folders are found on disk. Stray folders and files (e.g. `__MACOSX`, `.DS_Store`) are ignored. Test in Task 2.

### Task 3: `train.py`: optimisers, training loop, evaluation, resume

**Files:**
- Create: `train.py`, `tests/test_train.py`

**Interfaces:**
- Consumes: `build_model`, `CLASSES` from `model.py`
- Produces:
  - `make_optimizer(exp_id: str, model: nn.Module) -> torch.optim.Optimizer`. E1/E2: `SGD(lr=1e-3, momentum=0.9)`. E3/E5: `Adam(lr=1e-4)`. E4: `Adam` with two param groups, `features[24:]` at `1e-5` and `classifier` at `1e-4`. It only includes params with `requires_grad`.
  - `fit(model, optimizer, loaders: dict, epochs: int, device: str) -> tuple[nn.Module, list[dict]]` returns the model loaded with the **best-val-acc** weights and a history list of `{"epoch", "train_loss", "train_acc", "val_loss", "val_acc"}`. It uses `CrossEntropyLoss`.
  - `evaluate(model, loader, device) -> dict` with keys `acc: float`, `macro_f1: float`, `report: dict` (sklearn `classification_report(output_dict=True, target_names=CLASSES, labels=range(6), zero_division=0)`) and `confusion: list[list[int]]` (6×6).
  - `pending_experiments(results_csv: Path, wanted: list[str]) -> list[str]` returns the ids in `wanted` that are not yet in the CSV's `exp_id` column, keeping their order.

### Task 5: `app.py`: load, predict, Gradio UI

**Files:**
- Create: `app.py`, `tests/test_app.py`

**Interfaces:**
- Consumes: `build_model`, `eval_transform`, `CLASSES`, `BIN_INFO`

  - `load(path: Path, device: str = "cpu") -> tuple[nn.Module, dict]` returns the model in eval mode and the checkpoint metadata. It raises `FileNotFoundError` with the message `"weights/best.pt not found. Run notebooks/smartbin_training.ipynb first and copy best.pt into weights/"`.
  - `predict(model, image: PIL.Image | None) -> dict`:
    - `None` returns `{"error": "Please upload a photo of one waste item."}`.
    - Otherwise it returns `{"top3": [(class, prob), ...], "probs": dict[str, float] (all 6), "bin": str, "color": str, "tip": str, "warning": str | None}`. `warning` holds the low-confidence message when the top prob is `< 0.5`. The image goes through `exif_transpose` and then `.convert("RGB")` before the transform.
  - `build_ui(model, meta) -> gr.Blocks`; `if __name__ == "__main__":` loads `weights/best.pt` and launches.

```python
@pytest.mark.parametrize("exp_id", EXPERIMENTS)
def test_checkpoint_roundtrip(exp_id, tmp_path):
    m = build_model(exp_id, pretrained=False).eval()
    save_checkpoint(m, exp_id, 0.9, tmp_path / "b.pt")
    m2, meta = load(tmp_path / "b.pt")
    x = torch.randn(1, 3, 224, 224)
    assert meta["exp_id"] == exp_id and torch.allclose(m(x), m2(x))

def test_missing_weights(tmp_path):
    with pytest.raises(FileNotFoundError, match="Run notebooks"): load(tmp_path / "none.pt")

@pytest.mark.parametrize("img", [Image.new("RGB", (512, 384)), Image.new("RGBA", (300, 300)),
    Image.new("L", (200, 200)), Image.new("RGB", (40, 40)), Image.new("RGB", (4000, 3000))])
def test_predict_any_image(model, img):
    r = predict(model, img)
    assert len(r["top3"]) == 3 and abs(sum(r["probs"].values()) - 1) < 1e-4
    assert r["bin"] == BIN_INFO[r["top3"][0][0]]["bin"]

def test_predict_none(model):
    assert "error" in predict(model, None)

def test_low_confidence_warning(model):
    model.classifier[1].weight.data.zero_(); model.classifier[1].bias.data.zero_()  # → uniform 1/6
    assert predict(model, Image.new("RGB", (224, 224)))["warning"].startswith("Not sure")

def test_confident_no_warning(model):
    model.classifier[1].weight.data.zero_(); model.classifier[1].bias.data[:] = torch.tensor([9., 0, 0, 0, 0, 0])
    r = predict(model, Image.new("RGB", (224, 224)))
    assert r["warning"] is None and r["top3"][0][0] == "cardboard"

def test_exif_rotation_applied(model, monkeypatch):
    buf = io.BytesIO(); exif = Image.Exif(); exif[0x0112] = 6   # "rotate 90° CW to display"
    Image.new("RGB", (400, 200)).save(buf, "JPEG", exif=exif); img = Image.open(io.BytesIO(buf.getvalue()))
    seen = {}
    real = app.eval_transform()
    monkeypatch.setattr(app, "eval_transform", lambda: (lambda im: (seen.setdefault("size", im.size), real(im))[1]))
    predict(model, img)
    assert seen["size"] == (200, 400)   # portrait after transpose
```
